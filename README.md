# Lulu kids videos

Short animated videos for a YouTube kids channel (ages 3 to 10), made with code and published through Make.

- `toolkit/`: drawing library, video builder, soundtrack generator, media publisher
- `episodes/`: one folder per episode (scene + settings) and `log.json`, the list of published videos
- `channel/`: profile picture and banner
- `CLAUDE.md`: the production guide followed by each scheduled run
- `media` branch: holds only the latest finished video so Make can download it
